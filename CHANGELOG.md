# Changelog

## Duo Receiver 0.1.0

- First packaged Apple Silicon receiver release, for macOS 14 and later.
- Custom drag-to-Applications DMG with Retina artwork.
- Developer ID signing, app and DMG notarization, stapled tickets, and checksums.
- GitHub Actions for tests, both app builds, and versioned receiver releases.
- MIT license and simpler setup, gesture, development, security, and release guides.

The iPhone TestFlight beta remains version 1.0 (1).
